ActuallyCare is a real‑estate CRM platform designed for agents who truly care about their clients. It centralises client relationships, automates busywork with an AI assistant, and provides features like deal tracking, follow‑up reminders, and AI‑driven insights. Founded by licensed agent Jayden Metz, the service aims to make caring provable, offering a free‑setup, AI specialist support, and continuous feature releases to improve agent productivity and client satisfaction.

**Areas:** Real Estate CRM · AI Assistant · Deal Tracking · Partner Network

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for ActuallyCare: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
